使用指南

XUComer 是一款开源的键盘 / 鼠标按键音效模拟器。它常驻后台，全局监听你的每一次敲击， 实时播放对应的按键音。下面按使用顺序把每个功能讲清楚，全部看完约 5 分钟。

安装

软件是绿色免安装的，不需要管理员权限。

  1. 在首页点「下载」，选 Windows x64（多数电脑）或 Windows x86（较老的机器）。
  2. 下载得到 XUComer-win-x64.zip，右键解压到任意目录（例如 D:\XUComer）。
  3. 解压后目录里直接就是 XUComer.exe 和 _internal 文件夹，两个要放在一起，不要只复制 exe。
  4. 双击 XUComer.exe 即可运行。
不确定系统位数？ 按 Win + I 打开设置 → 系统 → 关于，看「系统类型」一栏。 64 位系统装 x64 即可；x86 版本功能完全一致，只是面向老旧设备。
杀毒软件误报？ 程序由 PyInstaller 打包且未做代码签名，个别杀软会误判。源码完全公开， 可自行核对；加入信任区即可。

启用与关闭

首次启动时软件处于未启用状态——顶部「启用」开关是灰的，这时敲键盘不会有任何声音。 这是为了避免一开机就打扰你。

  • 点一下顶部「启用」右侧的开关，变亮即开始工作。
  • 再点一下即关闭，键盘鼠标恢复安静。
  • 没有「启用」时，键盘和鼠标的试听按钮依然可用，方便先挑音色。

切换音效

主界面有两张卡片，分别是「键盘音效」和「鼠标音效」。

  1. 点卡片中间的下拉框，会列出所有可用音效包。
  2. 选中即切换，并自动试听一次。
  3. 内置 11 组键盘音效（绿轴、蓝轴、茶轴、线性、轻触等）与 14 组鼠标音效（G203、GPX、DeathAdder V2 等）。

每张卡片右上角还有一个开关，可以单独关掉键盘或鼠标的声音——比如只想让鼠标响、键盘保持安静。

调节音量

每张卡片下面都有音量滑条，范围 0 ~ 100，键盘与鼠标各自独立，拖动时右侧数字会实时变化，松手即保存。

试听

卡片标题右侧的「试听」按钮会播放一次「按下」的声音。试听不受「启用」开关影响，随时可用。

抬起音

真实的机械键盘按下与松开是两种声音。XUComer 支持把「抬起音」单独开关： 勾选卡片上的「抬起音」复选框即开启。

  • 部分音效包（主要是鼠标包）本身没有抬起音，此时该复选框会自动置灰。
  • 开启后每次松键也会发声，长按场景下更接近真实手感。
  • 不想听到松键声就不勾，只保留按下音。

导入自定义音效

想用自己的录音做音效，不用任何音频软件：

  1. 点卡片上的「导入自定义」。
  2. 选择音频文件，支持 wav / mp3 / ogg / flac / m4a 等常见格式。
  3. 键盘音效会询问是否为「抬起音」单独选一个文件。
    选否的话，程序会从按下音的尾部自动衍生一个抬起音。
  4. 输入音效包名称（默认 XUComer Custom N），确定。
  5. 等待几秒，处理完成后自动选中并试听。

导入时程序会自动完成这些处理：直流去除 → 首尾静音裁剪 → 多次击打切分 → 限长 260 毫秒 → 首尾淡入淡出 → 峰值归一化 → 生成多个微变速版本。

为什么要生成多个版本？ 连打时随机轮换不同版本，避免每次声音一模一样带来的机械感。

管理自定义音效

选中一个自定义音效包时，「删除」按钮会亮起，点击确认即可移除。 内置音效包不可删除，按钮始终置灰。

主题

点标题栏右侧的 ⚙ 按钮展开设置面板（它是一个独立小窗，不会改变主窗口大小、也不会遮住任何控件）。

  • 内置 40 套主题：28 套暗色 + 12 套浅色。
  • 下拉列表每项左侧有色块预览，选中立即生效。
  • 换主题不只是换颜色——圆角大小、边框粗细、内间距、标题字号、窗口宽度都会跟着变， 所以有方角工业风、大圆角卡片风、浅色网格风等不同版式。

语言

同一设置面板里的「语言」下拉，提供 18 种语言，外加默认的「跟随系统」：

简体中文 · 繁體中文 · English · 日本語 · 한국어 · Français · Deutsch · Español · Português · Русский · Italiano · Nederlands · Polski · Türkçe · العربية · ไทย · Tiếng Việt · Bahasa Indonesia

选择「跟随系统」时会读取 Windows 的显示语言自动匹配，切换即时生效，无需重启。

网页同步设置

本网站的右上角有两个选择器，和软件里的设置一一对应，方便你提前挑好：

  • 主题：一排色点，每一个都取自软件里的真实配色（共 40 套）。点一下，整个网页立刻换成该主题的底色、卡片色与强调色，和软件里选中时的观感一致。
  • 语言：支持与软件相同的 18 种语言，另有默认的「跟随系统」。切换后网页界面文字、导航与本节标题都会跟着变。

两个设置都会记在浏览器本地，下次打开自动沿用；换一台设备则需要重新选一次。

为什么主题里有亮有暗？ 软件本身就同时提供 28 套暗色与 12 套浅色主题，网页照搬了这个分类。 选到浅色主题时，网页会整站切成浅色排版，和软件里的效果一致。

托盘与开机自启

  • 托盘：设置面板里勾选「托盘」后，点关闭按钮不会退出程序，而是最小化到右下角托盘区，双击图标即可唤回窗口。
  • 开机自启：勾选「开机自启」后，程序会写入当前用户的启动项，下次开机自动运行（仍然默认不启用，不会一开机就响）。
  • 退出：点设置面板里的「退出」按钮可完全关闭程序。

设置保存在哪

所有设置自动保存，无需手动操作：

  • 配置文件：%APPDATA%\XUComer\settings.json
  • 自定义音效：%APPDATA%\XUComer\sounds\

把它们删掉即可恢复默认设置；覆盖安装或更换程序目录都不会丢失。

常见问题

敲键盘完全没声音？

先确认顶部的「启用」开关是否已打开（默认是关闭的）。其次检查对应卡片的开关、音量是否为 0。都正常的话，用「试听」按钮确认音效本身能否播放。

游戏里能听到吗？

可以。全局监听工作在系统层面，全屏游戏中同样发声。极少数带反作弊的游戏可能限制全局钩子，此时请以该游戏规则为准。

需要联网或管理员权限吗？

都不需要。所有音效都在本地，程序不发起任何网络请求，普通用户权限即可运行。

某些键偶尔没声音？

正常。程序按虚拟键码判重以保证长按不重复发声；程序每 3 秒自检一次监听状态，意外断开会自动恢复。若长时间异常，关掉再打开「启用」开关即可重置。

支持 macOS / Linux 吗？

目前仅 Windows。其他平台需要替换底层监听实现，欢迎提 Issue 或 Pull Request。

能二开吗？

可以。代码以 MIT 许可发布，允许修改和分发，只需保留版权声明。内置音效素材遵循各自原始授权，请一并遵守。
